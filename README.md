## Environment Setup

### Python Version

The code was developed and tested with:

```sh
Python 3.11.11
```

Create and activate a virtual environment (recommended):

```sh
python -m venv venv
source venv/bin/activate
```

Install dependencies:

```sh
pip install -r requirements.txt
```

## Data

### Training data
Training data is provided in the `data/` directory.

The following files are used for model training:

- `data/train_no_ne.json.gz`, a corpus of plain documents, where named entities are not explicitly marked.
- `data/train_sub_ne.json.gz`, a variant of the training corpus in which named entities are substituted with explicit markers, enabling controlled experiments on entity information.

Both datasets are preprocessed and ready to be used directly by the training pipeline.

### SocialIQA Subset

This artifact uses a reduced subset of the SocialIQA dataset.

- The subset is provided in: `data/reasoning_probes.json`
- This file contains a smaller selection of SocialIQA examples and is intended solely to reproduce the analyses reported in the paper.

### Up-to-date Wikipedia Documents

To obtain the latest Wikipedia content, run:

```sh
python utils/collect_up_to_date_docs.py
```

This script downloads and processes up-to-date Wikipedia documents locally. The resulting files are not included in this repository and must be generated by the user.

Wikipedia text content is licensed under the **[Creative Commons Attribution–ShareAlike 4.0 International (CC BY-SA 4.0)](https://creativecommons.org/licenses/by-sa/4.0/)**.


## Results

All quantitative results reported in the paper are included under:

```sh
output/
```

These files contain the final metrics and statistics used in the analysis. No intermediate checkpoints or additional artifacts are required to interpret the results.


### Additional Results

Additional experimental results that are not included in the main paper due to space constraints are provided in the `table/` directory.

This folder contains the full result tables corresponding to the summarized results discussed in the paper

## Analysis

The analysis directory contains Jupyter notebooks used to generate the plots and tables reported in the paper.

- Notebook outputs have been cleared to preserve anonymity.
- The notebooks can be re-executed using the data stored in `output`.


## Circuit Evaluation

The circuits directory contains all code related to circuit evaluation and analysis.

This includes:
- circuit discovery logic,
- evaluation metrics,
- supporting utilities.

Users interested in inspecting or re-running circuit evaluation should refer directly to the scripts in this directory.
